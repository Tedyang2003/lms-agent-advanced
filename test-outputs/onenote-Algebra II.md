## Quadratic Formula (10/17)

      

Wednesday, July 29, 2026

9:31 PM

Solving Quadratics: x = (-b ± √(b²-4ac)) / 2a

Discriminant rules:

*   b²-4ac > 0 → two real solutions
*   b²-4ac = 0 → one real solution
*   b²-4ac < 0 → no real solutions (complex)

HW: p.211 #1-15 odd

Example:

2x² + 5x - 3 = 0

a=2, b=5, c=-3

Step 1: b² - 4ac = 25 - (4)(2)(-3) = 25 + 24 = 49

Step 2: √49 = 7

Step 3: x = (-5 ± 7) / 4

x = 0.5 or x = -3
